# Taspia portfolio

Custom HTML, CSS and JavaScript portfolio, built with Vite, GSAP and Lucide.

## Local development

Run `npm install`, then `npm run dev`. Run `npm run build` for production output in `dist`.

## Content

Main content and metadata are in `index.html`. Notebook dialog entries are in `src/main.js`; these are clearly labelled illustrative independent samples. Styles and responsive layouts are in `src/style.css`. The downloadable résumé is in `public/documents/Taspia-Resume.pdf`.

Experience is limited to supplied role titles, employers and dates. No client outcomes or invented metrics are claimed. Replace the independent examples with approved work samples as they become available. Confirm the DSAT Scholars end month before changing its current date label.

The website uses Google Fonts with local system fallbacks. Contact uses an email link and clipboard button. No backend, visitor tracking or contact database is included.
